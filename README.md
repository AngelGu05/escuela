# Escuela

Apps de estudio para mis clases. Cada tema está en su propia carpeta y es un solo archivo `index.html`, sin dependencias.

Cada carpeta se publica como un sitio separado en Vercel (un proyecto por tema, con su "Root Directory" apuntando a la carpeta), así los temas no se enlazan entre sí.
